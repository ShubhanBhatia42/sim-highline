# Literature candidates: simulation papers (search only, nothing added to the data)

Date: 2026-10-06. Compiled by querying the arXiv API (title and author), so every id and title below was returned by arXiv. The "could supply" notes are read from titles and abstracts only and are marked "to check": whether a figure or table exists in vector form, and which definitions it uses, has to be confirmed before extraction.

## Why sim-highline has "only" 111 citations

The 111 are the distinct DOIs or URLs of papers and data releases that already supply at least one plotted curve (simulation and observational). sim-highline extracts relation curves, not every paper about a simulation, so a suite with many papers can still contribute one or two. This search lists the wider set: flagship, data-release, method and specialised-suite papers, which are what the Simulations page and the next extraction rounds need. Search coverage is limited by arXiv title matching; some well-known papers did not match (for example the FABLE, Auriga II, MARVEL and Eris overviews, GALFORM, and the MP-Gadget and SPHENIX code papers) and need a manual lookup.
