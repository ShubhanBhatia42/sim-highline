# Dials page: a 90-second demonstration

Open the dials page. Start in the default state (both universes at their default dials).

1. **0:00** "These are two well-known simulated universes. They grow galaxies from the same kind of start but disagree about how violently exploding stars and black holes push gas around. Each has four dials." Point at the sentence above the charts: it says how many of the eleven galaxy properties agree right now.
2. **0:15** Drag *Supernova wind strength* in one universe to the right. "Watch the stellar mass function and the star formation panels move. The shaded band is what this dial can reach on its own." Reset.
3. **0:30** Leave *Match on* at the stellar mass function and press *Make SIMBA look like TNG*. Read the story aloud: which dials moved, how the gap on the mass function changed, what came into line and what was knocked out.
4. **0:50** Change *Match on* to *black hole occupation* and press the button again. "Here is a property no dial setting can fix: in one universe nearly every galaxy has a black hole, in the other low-mass galaxies have none." Point at the gap number (above 9).
5. **1:10** Press *Reset*, then *Closest the two can get* with *Match on* set to everything. "Tuning one thing breaks others. Even the best compromise leaves them agreeing on only a few of eleven."
6. **1:25** Click the link to the study. "How big this is in real units, and how it was tested, is written there, with the rules fixed before we looked."

Things to say if asked: the curves are approximate near the edge of the dial ranges; it is two codes only; no one has checked this beyond the project.
