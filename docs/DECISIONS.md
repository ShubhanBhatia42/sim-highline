# Decisions

Newest first. Each entry says what was decided, why, and what would reverse it.

## 2026-10-16

- **A speed-up of the emulator code that changes no number.** `quad_features` (scripts/modelform_stats.py) now builds the polynomial features from precomputed index arrays, and `_grad_pred` and `astro_x` (scripts/analyze_model_form.py) build their points without loops. These sit under the registered analyses, so the rule was: results must be identical bit for bit. Checked on random inputs (all dimensions and degrees) and on a full distance search (same distance to the last digit, same hash of the result), and by the saved-output tests of both analyses. Reason: the joint-reachability test took about ten minutes; it now takes under two on four cores. Reverses if any saved result ever differs.
- **The slow tests are skipped locally when nothing they read has changed; CI always runs them.** Reason: a check nobody runs because it is slow protects nothing. `FRESH=1` forces them.
- **The share-preview images are generated by a script and committed.** Reason: the chart on each card is the page's own chart, which needs a browser to draw; a build that needs a browser everywhere would be slower and more fragile. A stale image is a cosmetic fault, so it is regenerated by hand (`make og`).
- **Content-Security-Policy as a meta tag with the hash of every inline script.** Reason: the host (GitHub Pages) does not let us set headers. A meta policy cannot restrict framing, so that part is not covered. Styles stay `unsafe-inline` because the pages use inline style attributes.
- **No separate Research page.** The four studies stay on the front page below the tools and on the Studies page. Reason: a second layer of navigation adds a click for nobody's benefit. Reverses if visitors cannot find them.
- **The menu calls the dials page "Dials".** The address stays `retune.html` so links survive.
- **The front door is "check your own run" and "turn the dials", not the studies.** Reason: the studies are evidence, the tools are what someone returns for. Reverses if pilot users go to the studies first.
- **Study codes (S1 to S4) are dropped from everything a visitor reads.** Reason: nobody remembers them. The files keep their names; pages use plain titles.
- **Retune matches one property at a time by default.** Reason: matching everything at once reports "agree on 2 of 11", which hides what tuning can do. Matching one property shows the trade-off it causes.
- **Native units (dex, fraction) are shown beside noise units.** Reason: "4.8 noise units" means nothing to a reader; one noise unit is 0.04 to 0.18 dex depending on the property.
- **Success and stopping rules are written down (PROJECT.md).** Reason: the decision to continue should rest on outside use, not on how much has been built.
