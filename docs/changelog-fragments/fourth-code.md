## Changelog bullets (task: fourth-code)

- Measured conversions, a fourth code: Swift-EAGLE (CAMELS, 27 fiducial boxes, z = 0, 0.95 and 2.15, 81 Subfind catalogue files) is added to `data/conversions.json` and `docs/CONVERSIONS.md` with the same schema and the same seed-to-seed error bars as IllustrisTNG, SIMBA and Astrid. The earlier statement that the public Swift-EAGLE runs have no catalogues was wrong: only the `Sims` tree of the CAMELS server had been looked in; the catalogues are in the `FOF_Subfind` tree. What differs for this code is written on the page: it is read from another tree and was probably made by a separate Subfind run, and the SFR within 2 R_half falls below the total at high mass (-0.03 to -0.35 dex above log M* 10.5), which the other three codes do not do. The CAMELS pages name no paper for this variant and no data licence, and say a bug in the Swift-EAGLE catalogues was fixed in the public directories (not tested here).
- The numbers for the first three codes are unchanged (their blocks in `data/conversions.json` are byte-identical to before; only the "about" sentence says four codes instead of three). Because the CAMELS pages report a catalogue bug in some sets, the arrays read for the first three codes were compared with the current `FOF_Subfind` files: 243 of 243 (code, box, snapshot) files give the same SHA-256.
- Candidates for further codes were checked and written up with the HTTP evidence in `docs/EXPANDING-COVERAGE.md`: the other CAMELS suites (Magneticum, Ramses, CROCODILE, Obsidian, Enzo) are private (a form), EAGLE and Magneticum need an account, TNG/Illustris need a key, the FIRE-2 public data are particles for a few zoom-in galaxies (not done: a measurement from three or a few more galaxies would not be comparable to a 27-box one), FLAMINGO SOAP access and the Horizon-AGN and SIMBA main-run sites could not be settled from here. Not done: a resolution test for any code.
- Remove from the Unreleased list: "Not done: measured conversions for a fourth code (the public Swift-EAGLE runs have no catalogues) ..." (the second half of that sentence, about survey selection effects, still holds).
