- Explorer, figures: the footer of an exported figure (SVG and PNG), the methods text and the figure pack now carry a caveat line that is generated from the comparison rules, not typed. It calls `compatible` between the plotted curves and says which of them differ in a definition that must agree for the relation (named with the plain labels of `KEY_LABEL`, with the curves on each side), which are context only, and which smaller differences remain (IMF, mass definition, cosmology and the rest of the relation's soft keys); if nothing differs it says the curves are like for like. The raw-key list of differences in the methods text and the fixed caption sentence of the pack are replaced by it. Internal checks only: `scripts/test-logic.mjs` and `scripts/test-ui.mjs`; no outside expert has reviewed the wording.

With it off the page is unchanged. With it on, the plot, legend, offsets, offsets table, disagreement view, evidence panel, figure, methods text and page link (`osc=`) say that the plotted values are not the published ones; observations, records and downloads are not transformed. It is not a model of any survey. `observer-lib.js` is inlined into the Explorer without its comments (about 2.9 kB compressed); the first visit goes from 240 to 248 kB of its 260 kB budget.
