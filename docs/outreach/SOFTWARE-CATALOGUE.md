- **Title:** sim-highline
- **Authors:** Shubhan Bhatia
- **Abstract:** sim-highline is a Python package and web application for galaxy scaling relations from cosmological simulations. The package loads a curated dataset of 1,736 curves with their definitions and provenance into pandas, selects curves by relation and redshift, and compares a user's curve with the published ones, reporting offsets only where the definitions allow it. The web application plots simulations and observations together and evaluates emulators of the CAMELS IllustrisTNG and SIMBA suites in the browser. Nothing is interpolated.
