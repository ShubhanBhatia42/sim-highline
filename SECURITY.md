# Security and data-integrity reports

sim-highline is a static dataset and website with no accounts, server or user data. The things worth reporting are:

- **A wrong or misattributed record** (values that do not match the source, wrong definitions, wrong citation): open a "Curve error" issue, or use the Report an issue button on the curve in the app.
- **A licence or permission concern** about any record (see `docs/SOURCE-TERMS.md`): open an issue, or use the contact address in `CITATION.cff` if you prefer not to post publicly. Records are corrected or removed promptly on request.
- **A vulnerability** in the build scripts, workflows or website: please use GitHub's private vulnerability reporting for this repository (Security tab), or the contact address in `CITATION.cff`.

Only the latest release (`data/release.json`) is supported.
